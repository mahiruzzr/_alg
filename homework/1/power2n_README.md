# power2n 效能比較

計算 `2^n` 的四種寫法，以 `n = 100` 測試正確性與速度。

正確值：`2^100 = 1267650600228229401496703205376`

## 檔案

* `power2n.py`：四種實作 + 效能測試主程式

## 四種方法

原稿四個函數都命名為 `power2n`，Python 會互相覆蓋只剩最後一個，因此實作時改名區分，並統一補上遞迴終止條件 `n == 0: return 1`。

| 方法 | 寫法 | 複雜度 | 說明 |
|---|---|---|---|
| 方法 1 `power2n_v1` | `return 2**n` | O(log n) | 直接用內建次方，最快 |
| 方法 2a `power2n_v2a` | `power2n(n-1) + power2n(n-1)` | O(2^n) | 每次分裂成兩個相同子問題，重複計算太多，跑不出來 |
| 方法 2b `power2n_v2b` | `2 * power2n(n-1)` | O(n) | 每次只遞迴一次，線性時間 |
| 方法 3 `power2n_v3` | 遞迴 + 查表 (memoization) | O(n) | 算式同 2a，但 `n-1` 只算一次並存入 `memo`，避免重複展開 |

## 測試結果

執行：

```powershell
chcp 65001 | Out-Null; $env:PYTHONIOENCODING="utf-8"; python power2n.py
```

`n = 100` 實測：

* 方法 1：正確，約 1.1 us
* 方法 2b：正確，約 18.3 us
* 方法 3：正確，約 21.7 us
* 方法 2a：出不來，呼叫次數約 `2^101`，無法在合理時間完成

方法 2a 改用小 n 示範指數爆炸：

* n=10：約 0.11 ms
* n=15：約 3.6 ms
* n=20：約 179 ms
* n=22：約 1334 ms

n 每加 1 時間約變兩倍，n=100 為天文數字。

## 結論

方法 1 > 方法 2b ≈ 方法 3 >> 方法 2a（不可用）。

要算大 n 的 `2^n` 用方法 1；要練習遞迴用方法 2b；要練習查表優化用方法 3；方法 2a 僅具教學意義，說明 naive 遞迴為何會爆炸。
