## 2. 參考資料研讀

1. 習題所附 Gemini 分享（Lambda Calculus、函數式程式語言）：確認需涵蓋 Church booleans / numerals、beta/alpha、Y combinator、求值策略。
2. 課程參考實作 `lambdaCalculus.py`（已讀取全文）：
   - 它是「Python 內嵌 Church encoding」：用 Python 的 `lambda` 直接當 Church boolean/number，無 lexer/parser，執行即求值，**看不到任何化簡步驟**。
   - 本專案與其差異是刻意的：習題要的是「解譯器 + 完整過程」，所以必須自寫 tokenizer / parser / AST / substitution / 單步 reduction / trace，而不是沿用 Python lambda。
   - 為保持銜接，`examples/prelude.lc` 的定義（TRUE/FALSE/AND/OR/SUCC/ADD/MULT/PRED/Y/CONS/CAR…）與該參考實作語義一致，範例（階乘、fib 概念、RANGE/MAP 概念）對應其測試項目。

## 4. 設計決策

| 項目 | 決策 | 理由 |
|---|---|---|
| 語法 | `\x.`、`λx.`、`lambda x.` 皆可；`\x y.` 多參數糖；`NUMBER` 展開為 Church numeral；`#` 註解；一行一 statement | 教學常用寫法全支援，數字糖讓算術範例簡潔 |
| 化簡 | normal-order（最左最外）預設；applicative（最左最內）可切換 | normal 保證找到 normal form；兩者對比 `(λx.y) Ω` 是經典教材情節 |
| 代換 | capture-avoiding + 每次 α-conversion 印出說明並用 fresh `vN` | 習題常見扣分點就是變數捕捉，必須顯式展示 |
| 沒名稱版 | De Bruijn index，`to_debruijn/from_debruijn`，自由變數以 `DbFree` 保留原名 | 純理論 closed term 才有純 index；保留原名讓所有範例都能雙顯示 |
| 解碼 | 結果自動判讀 Church numeral/boolean；`FALSE`/`0` 同 term 則標註雙重身分 | 新手最需要「λf.λx.f(f x) = 2」的橋樑；歧義不隱瞞 |
| 步數上限 | 預設 100 步，`--max-steps` 可調；超限明確報「可能發散」 | Ω、Y-發散必須有出口；實測 FACT 1=36 步、FACT 2=142 步、FACT 3=694 步 |
| 相容性 | 純標準函式庫；規則標記全用 ASCII（`beta:`/`alpha-conversion`/`[OK]`/`...`）；中文訊息用 utf-8 | Windows cp950 下特殊符號會直接崩潰，已實測修復 |
