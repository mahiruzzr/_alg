# 旅行推銷員問題 (TSP):五種解法比較

以同一組隨機城市,分別用五種方法求解旅行推銷員問題 (Traveling Salesman Problem),並比較路徑長度與執行時間。

| 編號 | 方法 | 類型 |
|---|---|---|
| 1 | 改良法 (2-opt) | 區域搜尋(完整掃描) |
| 2 | 爬山演算法 (Hill Climbing) | 區域搜尋(隨機取樣,只接受更好的解) |
| 3 | 模擬退火法 (Simulated Annealing) | 隨機化搜尋(可接受較差的解) |
| 4 | 梯度下降法 (Elastic Net) | 連續能量函數最佳化 |
| 5 | 貪婪演算法 (最近鄰居法) | 建構式啟發法 |

## 方法說明

### 1. 改良法 (2-opt)
從隨機路徑出發,掃描所有「拆掉兩條邊、反轉中間一段」的交換,只要能縮短總長度就採用,直到找不到可改良的交換為止。

### 2. 爬山演算法
隨機挑一個鄰居(反轉一段路徑),只接受更短的解。不接受變差的解,因此容易卡在局部最佳解。

### 3. 模擬退火法
鄰居與爬山法相同,差別在接受準則:變差的解也以機率 `exp(-Δ/T)` 接受,溫度 `T` 以 `T ← αT` 逐步下降。前期可跳出局部最佳解,後期趨近爬山法。

### 4. 梯度下降法 (Elastic Net)
TSP 是離散問題,無法直接對路徑微分。這裡採用 Durbin & Willshaw 的彈性網:放一個由 `m` 個節點 `y_j` 組成的彈性環,定義連續能量函數

```
E = -αK Σ_i ln Σ_j exp(-|x_i - y_j|² / 2K²)  +  (β/2) Σ_j |y_{j+1} - y_j|²
```

第一項把環拉向城市 `x_i`,第二項讓環保持短而平滑。每次迭代沿 `-∇E` 更新節點(梯度下降),並逐步縮小 `K` 讓環貼近城市。最後依每個城市最接近的環節點順序,讀出拜訪順序。

### 5. 貪婪演算法 (最近鄰居法)
從起點出發,每一步都走向最近的未拜訪城市。速度最快,但最後常被迫走很長的回程,品質通常最差。

## 參數

| 方法 | 參數 | 預設值 |
|---|---|---|
| 爬山演算法 | `max_iter` | 200000 |
| 模擬退火法 | `T0` / `T_min` / `alpha` / `moves_per_temp` | 100 / 1e-3 / 0.995 / 100 |
| 梯度下降法 | `iters` / `alpha` / `beta` / `K0` / `K_min` | 8000 / 0.2 / 2.0 / 0.2 / 0.01 |

所有方法都固定從城市 0 出發,並回到城市 0。

## 範例結果(n = 30)

| 方法 | seed=42 | seed=7 |
|---|---|---|
| 1. 改良法 (2-opt) | 467.41 | 528.12 |
| 2. 爬山演算法 | 475.60 | 534.07 |
| 3. 模擬退火法 | **457.46** | **499.78** |
| 4. 梯度下降法 (Elastic Net) | **457.46** | 523.56 |
| 5. 貪婪演算法 | 588.84 | 583.35 |

隨機起始路徑的長度約 1700。

**觀察**

- 模擬退火在這兩組資料上最穩定,貪婪演算法最差。
- 改良法與爬山法會卡在局部最佳解,結果取決於起始路徑。
- 梯度下降(彈性網)不保證最佳解,不同資料上表現起伏較大。
- 以上僅為兩個種子的結果,並非嚴謹的統計比較。若要做正式比較,建議多跑幾組種子取平均。

## 備註

- 路徑長度為歐氏距離下的封閉迴路總長。
- 爬山、模擬退火與改良法共用同一條隨機起始路徑;貪婪與彈性網不需要起始路徑。
- 這些方法皆為啟發式演算法,不保證得到全域最佳解。
