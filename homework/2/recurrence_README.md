# 遞迴方程式求解說明

對應程式：`recurrence.py`

執行：

```powershell
python recurrence.py
```

程式內容：每題各有 `T_rec`（照定義直接遞迴）和 `T_closed`（封閉解），
主程式會比對兩者是否一致，並印出成長速度與執行時間。

## 1. T(n) = T(n-1) + 8, T(1) = 1

展開：

```
T(n) = T(1) + 8*(n-1) = 1 + 8n - 8 = 8n - 7
```

複雜度：`O(n)`，線性成長。

## 2. T(n) = 2*T(n-1) + 9, T(1) = 1

展開（等比數列求和）：

```
T(n) = 2^{n-1}*T(1) + 9*(2^{n-1}-1)/(2-1)
     = 2^{n-1} + 9*2^{n-1} - 9
     = 5*2^n - 9
```

驗算：`n=1 -> 5*2-9=1`，`n=2 -> 20-9=11=2*1+9`。

複雜度：`O(2^n)`，指數成長，n 稍大就爆炸。
這就是前面 `power2n` 方法 2a 會跑不出來的原因。

## 3. T(n) = 2*T(n/2) + 1, T(1) = 1

設 `n = 2^k`，展開 k 層：

```
T(n) = 2^k*T(1) + (2^k - 1) = 2n - 1
```

複雜度：`O(n)`。
Master theorem：`a=2, b=2, n^{log2 2}=n`，`f(n)=1`，屬 case 1。

注意：封閉解 `2n-1` 僅在 n 為 2 的冪時精確成立，
程式驗證也只用 `1, 2, 4, 8, 16, ...`。

## 4. T(n) = T(n/2) + 1, T(1) = 1

設 `n = 2^k`，展開 k 層：

```
T(n) = T(1) + k = 1 + log2(n)
```

複雜度：`O(log n)`。
Master theorem：`a=1, b=2, n^{log2 1}=1`，`f(n)=1`，屬 case 2。

同樣封閉解僅在 n 為 2 的冪時精確成立。

## 總表

| 題號 | 遞迴式 | 精確解 | Big O |
|---|---|---|---|
| 1 | T(n-1)+8 | 8n-7 | O(n) |
| 2 | 2T(n-1)+9 | 5*2^n-9 | O(2^n) |
| 3 | 2T(n/2)+1 | 2n-1（n=2^k） | O(n) |
| 4 | T(n/2)+1 | log2(n)+1（n=2^k） | O(log n) |

成長速度：`T2 >> T1 ≈ T3 >> T4`。
